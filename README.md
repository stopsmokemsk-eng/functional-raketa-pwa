# Функциональная РАКЕТА — восстановленный PWA-прототип

Загрузка состоит из трёх частей: оболочка и PWA; app.js; photos.js. До появления всех файлов проект не готов к публикации.

## Публикация
Статический проект без сборки и внешних JS-зависимостей. Все файлы в корне HTTPS-сайта. Vercel: Framework Other, Build Command пустой, Output Directory корень (.), Root Directory папка с index.html.
Локально: python3 -m http.server 8080 → http://localhost:8080. Для установки на телефон нужен опубликованный HTTPS URL.
Android: Chrome → меню → Установить. iPhone: Safari → Поделиться → На экран Домой. Из Telegram: меню → Открыть в браузере или скопировать ссылку в Safari. ОС контролирует системные панели; kiosk не реализован.

## Демо
Профиль → Администратор → пароль 111. Список подопечных, поиск, замеры, редактирование программы, обзор и рекомендации. Через смену локального профиля можно проверить рекомендации в чате.
Регистрация и данные только в текущем браузере; серверной авторизации и межустройственной синхронизации нет. 111 — не защита. Не вводить чувствительные данные.

## Возможности
Сегодня, карта тела, прогресс/фото, 360°, чат, профиль, регистрация, тренер/галерея, кабинет тренера. Дневные отметки, питание/рецепт, таймер, экспорт JSON, сброс.
3D — объёмные поверхности с перспективой и освещением, не скан и не прогноз. Талия влияет на торс, остальные параметры показаны численно. Медицинские анализы, соревнования и push не реализованы.

## Фото
photos.js: уменьшенные JPEG-копии трёх присланных снимков, ширина до 120 px. Это реальные фото, не генеративная подмена; для финальной версии заменить data URI оригиналами высокого разрешения.
PNG-иконки 192/512 встроены в manifest как data URI. Установку проверить на реальных устройствах; для production вынести PNG в отдельные файлы и добавить apple-touch-icon.

## Проверка и обновления
Node syntax и headless Chromium: страницы, регистрация, админ 111, изменение программы, рекомендация в чате, Canvas, offline reload — успешно. Pageerror: 0. Реальные iOS/Android и Telegram install не проверены.
При обновлении повысить CACHE в sw.js и закрыть старые вкладки. Production требует backend, роли, приватную базу и хранение фото, согласия и синхронизацию.
